# DataNova — тайлан, өгөгдөл борлуулах сайт

Судалгааны тайлан, тойм, цэвэр хүснэгт зардаг энгийн вэб. Бэлэн курсийн ажил зардаггүй.

Энэ репо бол **эх код**. GitHub Pages энэ дэлгүүрийг ажиллуулж чадахгүй. Нийтэд нээхийн тулд Render ашиглана.

## Олон нийтэд нээх (Render)

1. GitHub-аар [Render](https://dashboard.render.com/register) дээр нэвтэрнэ
2. Энэ товчийг дарна: [Deploy to Render](https://render.com/deploy?repo=https://github.com/batsukh1111/datanova)
3. **Apply** дарна
4. Хэдэн минут хүлээгээд `https://datanova.onrender.com` (эсвэл Render өгсөн хаяг) нээнэ
5. Удирдлагын нууц үг: Render → Environment → `ADMIN_PASSWORD`

Үнэгүй хувилбар 15 минут хүн ороогүй бол унтна. Дараагийн хүн ороход 1 орчим минут хүлээнэ.

## Компьютер дээрээ асаах

1. `data/admin.example.json` файлыг хуулаад `data/admin.json` болгоно
2. Доторх нууц үгээ өөрөө тавина
3. `run.bat` дар, эсвэл `python server.py`
4. Дэлгүүр: http://127.0.0.1:8787
5. Удирдлага: http://127.0.0.1:8787/admin

Удирдлагаас:
- тайлан нэмэх, засах, устгах
- захиалга харах, төлөв солих
- дэлгүүрийн нэр, данс, имэйл засах

## Захиалга

Худалдан авагч банкаар төлнө. Захиалга `orders/` хавтсанд хадгалагдана. Төлбөр орсон эсэхийг шалгаад файлыг имэйлээр илгээнэ.

Нууц үг, захиалгын файл GitHub руу орохгүй.
